## 1. أنظمة وقت التشغيل وأدوات التطوير

### vibeside-mcp
- **الإصدار الحالي**: `v0.30.0`
- **بيئة التشغيل**: Node.js >= 20.0.0 / Standalone Native Binary
- **البروتوكول**: Model Context Protocol (MCP) v1.0
- **القياس عن بعد**: FastMCP Direct IPC / CDP Port 9315
- **الميزات**: قياس أداء FPS من جانب العميل وفاحص طبقات GPU

### omnibrowse
- **الإصدار الحالي**: `v0.17.0`
- **بيئة التشغيل**: Rust 1.80+ (Dual-Core Engine)
- **الميزات**: محرك النقل فائق السرعة الذكي HTTP/3 و QUIC

- **الإصدار الحالي**: `v0.29.0`
