## 1. रनटाइम और देव उपकरण

### vibeside-mcp
- **वर्तमान संस्करण**: `v0.33.0`
- **रनटाइम लक्ष्य**: Node.js >= 20.0.0 / Standalone Native Binary
- **प्रोटोकॉल**: Model Context Protocol (MCP) v1.0
- **टेलीमेट्री**: FastMCP Direct IPC / CDP Port 9315
- **मुख्य विशेषताएं**: क्लाइंट-साइड एफपीएस टेलीमेट्री और जीपीयूर लेयर इंस्पेक्टर

### omnibrowse
- **वर्तमान संस्करण**: `v0.22.0`
- **रनटाइम लक्ष्य**: Rust 1.80+ (Dual-Core Engine)
- **मुख्य विशेषताएं**: बुद्धिमान HTTP/3 और QUIC उच्च गति परिवहन इंजन

### binvibe
- **वर्तमान संस्करण**: `v0.29.0`
- **रनटाइम लक्ष्य**: Rust Native PE/ELF Decompiler Bridge
- **मुख्य विशेषताएं**: बाइनरी एन्ट्रापी झरना और माइक्रो-बनावट विज़ुअलाइज़र
