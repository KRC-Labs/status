## 1. Sistemi Runtime & DevTools

### vibeside-mcp
- **Versione Attuale**: `v0.30.0`
- **Target Runtime**: Node.js >= 20.0.0 / Standalone Native Binary
- **Protocollo**: Model Context Protocol (MCP) v1.0
- **Telemetria**: FastMCP Direct IPC / CDP Port 9315
- **Caratteristiche**: Telemetria FPS lato client & ispettore layer GPU

### omnibrowse
- **Versione Attuale**: `v0.17.0`
- **Target Runtime**: Rust 1.80+ (Dual-Core Engine)
- **Caratteristiche**: Motore di trasporto intelligente HTTP/3 & QUIC

## 2. Sistemi Distribuiti & di Sicurezza

### remote-auto-ai-worker
- **Versione Attuale**: `v1.15.0`
- **Target Runtime**: TypeScript Serverless Gateway
- **Caratteristiche**: Politica di sicurezza dei contenuti (CSP) & sintetizzatore SRI

### vulnforge-mcp
- **Versione Attuale**: `v1.25.0`
- **Target Runtime**: Static & Dynamic Forensic Engine
- **Caratteristiche**: Isolamento micro-VM & gateway di attestazione sandbox

### binvibe
- **Versione Attuale**: `v0.29.0`
- **Target Runtime**: Rust Native PE/ELF Decompiler Bridge
- **Caratteristiche**: Cascata di entropia binaria & visualizzatore micro-texture

## 3. Motori di Rete, Controllo & Media

### omni-control-mcp
- **Versione Attuale**: `v1.13.0`
- **Target Runtime**: TypeScript Orchestrator
- **Caratteristiche**: PKI CA Zero-Trust & mesh mTLS con 28 strumenti MCP

### netvibe
- **Versione Attuale**: `v0.5.0`
- **Target Runtime**: C/Rust Native Low-Level Engine
- **Caratteristiche**: Forensica autonoma dei protocolli di controllo BGP-4 e OSPF

### webarcheology-mcp
- **Versione Attuale**: `v1.14.0`
- **Target Runtime**: TypeScript Forensics Engine
- **Caratteristiche**: Header di sicurezza client & simulatore di bypass CSP

### vidcompact-mcp
- **Versione Attuale**: `v1.11.0`
- **Target Runtime**: C++/Node.js Media Pipeline
- **Caratteristiche**: Codifica a due passaggi con accelerazione hardware

### omni-audio-mcp
- **Versione Attuale**: `v1.0.0`
- **Target Runtime**: WebAudio / Native DSP Engine
- **Caratteristiche**: Telemetria dello spettro audio FFT a 512 bande
