## 1. Системы выполнения и инструменты разработки

### vibeside-mcp
- **Текущая версия**: `v0.33.0`
- **Целевая среда**: Node.js >= 20.0.0 / Standalone Native Binary
- **Протокол**: Model Context Protocol (MCP) v1.0
- **Телеметрия**: FastMCP Direct IPC / CDP Port 9315
- **Функции**: Клиентская телеметрия FPS и инспектор слоев GPU

### omnibrowse
- **Текущая версия**: `v0.22.0`
- **Целевая среда**: Rust 1.80+ (Dual-Core Engine)
- **Функции**: Интеллектуальный транспортный движок HTTP/3 и QUIC

## 2. Распределенные системы и безопасность

### remote-auto-ai-worker
- **Текущая версия**: `v1.20.0`
- **Целевая среда**: TypeScript Serverless Gateway
- **Функции**: Политика безопасности контента (CSP) и синтезатор SRI

### vulnforge-mcp
- **Текущая версия**: `v1.29.0`
- **Целевая среда**: Static & Dynamic Forensic Engine
- **Функции**: Изоляция микро-ВМ и шлюз аттестации песочницы

### binvibe
- **Текущая версия**: `v0.29.0`
- **Целевая среда**: Rust Native PE/ELF Decompiler Bridge
- **Функции**: Водопад энтропии бинарных файлов и визуализатор текстур

## 3. Сетевые движки, плоскость управления и медиа

### omni-control-mcp
- **Текущая версия**: `v1.15.0`
- **Целевая среда**: TypeScript Orchestrator
- **Функции**: Zero-Trust PKI CA и сетка mTLS с 28 инструментами MCP

### netvibe
- **Текущая версия**: `v0.5.0`
- **Целевая среда**: C/Rust Native Low-Level Engine
- **Функции**: Криминалистический анализ протоколов BGP-4 и OSPF

### webarcheology-mcp
- **Текущая версия**: `v1.14.0`
- **Целевая среда**: TypeScript Forensics Engine
- **Функции**: Заголовки безопасности клиента и симулятор обхода CSP

### vidcompact-mcp
- **Текущая версия**: `v1.13.0`
- **Целевая среда**: C++/Node.js Media Pipeline
- **Функции**: Аппаратное 2-проходное кодирование и целевое сжатие

### omni-audio-mcp
- **Текущая версия**: `v1.0.0`
- **Целевая среда**: WebAudio / Native DSP Engine
- **Функции**: Телеметрия спектра аудио с 512 полосами FFT
